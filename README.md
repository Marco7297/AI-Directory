## Error handling

Unhandled runtime errors, promise rejections, and browser storage, media, audio, and uploaded-image errors are logged to the console and shown in dismissible in-app alerts. Failed external tool and agent logos fall back to their local icon or initials without interrupting browsing. React rendering failures are logged and replaced with a reload fallback. Expected browser autoplay-policy rejections are not reported.
